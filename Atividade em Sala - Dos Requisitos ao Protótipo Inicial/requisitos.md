# Requisitos Implementados

Neste protótipo em linha de comando, foram implementados os seguintes requisitos do sistema de estacionamento:

## 1. Visualização de Vagas
O sistema deve exibir visualmente quais vagas estão livres e quais estão ocupadas no momento exato do acesso, simulando a visão em tempo real.

## 2. Restrição de Vagas de Funcionários
O sistema deve validar e alertar o aluno caso ele tente selecionar ou estacionar em uma vaga exclusiva para funcionários, evitando o uso indevido de espaços restritos.
