# Protótipo - App de Estacionamento

Este protótipo em linha de comando simula as funcionalidades principais do sistema de estacionamento do campus.
Ele cobre dois requisitos principais:
1. Visualização em tempo real das vagas (livres e ocupadas).
2. Validação e restrição de acesso a vagas exclusivas para funcionários.

**Como executar:**
Certifique-se de ter o Python instalado e rode o comando abaixo no terminal:
`python3 main.py`
